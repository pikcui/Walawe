# 0004. Smart Accounts and x402 for Machine Payments

- Status: Accepted
- Date: 2026-11-06

## Context
Walawe needs to support machine-to-machine payments using x402 (HTTP 402 + USDC) in v1. The platform must remain non-custodial (the user's master key never touches our servers).

## Decision
1. We will use ERC-4337 (Account Abstraction) smart accounts deployed on Base.
2. Walawe agents will use **scoped session keys** generated by the user's wallet.
3. Session keys will have hard limits enforced by the smart contract:
   - Max spend per transaction.
   - Expiration time.
   - Destination allowlist (specific API provider addresses).
4. x402 payments will be facilitated by signing an EIP-3009 `transferWithAuthorization` payload using the session key.

## Consequences
- The Go gateway must be able to generate and verify EIP-712 signatures.
- We need a Solidity contract for the Account and the Session Key validation.
- Users must interact with a frontend to provision session keys (v1 dashboard feature).
